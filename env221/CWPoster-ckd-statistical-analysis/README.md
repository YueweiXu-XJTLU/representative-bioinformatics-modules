# CKD statistical analysis

[Poster](reports/poster.pdf) · [presentation script](presentation/presentation-script.pdf) · [R analysis](R/Scripts.R) · [figures](Figure/) · [narration](Audio/Cut/)

The project examines descriptive statistics, hemoglobin differences, hypertension/diabetes interactions, and the relationship between blood urea and serum creatinine. Run `Scripts.R` from `R/`; it reads the shared CKD input and retains the cleaned dataset locally.

The poster was converted from PowerPoint to PDF. Its original PNG replaces an unsupported WMF plot, and three text areas were resized to keep the conversion readable. Wording, results, and the overall layout are preserved. The narration script was converted from Word to PDF. The statistical analysis was not rerun.

***This repository contains coursework for educational purposes only and should not be treated as a rigorously validated academic reference.***
