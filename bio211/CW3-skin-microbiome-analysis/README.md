# Skin microbiome analysis

[Report](reports/report.pdf) · [analysis notes](analysis-notes.md) · [figures](Figures/)

The four analysis directories under [R/](R/) cover taxonomic composition and MaAsLin3 associations, pollutant correlations, alpha diversity, and beta diversity. Each contains its R script and saved results. Run the scripts in that order.

Input datasets and repeated intermediate tables are shared in [data/](data/). MaAsLin3 model objects, tables, logs, and individual figures are retained. These are archived analysis outputs; the models were not fitted again during repository preparation.
