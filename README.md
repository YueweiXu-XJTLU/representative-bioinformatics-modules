# Representative Bioinformatics Modules

A collection of representative modules during undergraduate study in XJTLU. Contents include learning materials, lab exercise, submitted coursework, and practical projects, across bioinformatics, genetics, machine learning, structural biology, statistics, etc. Each module has its own directory and a short guide.
