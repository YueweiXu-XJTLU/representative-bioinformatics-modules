# ACE2 docking analysis

[Report](reports/report.pdf) · [protein–protein docking](Q1/) · [protein–ligand docking](Q2/)

The archive retains ClusPro models, SwissDock variants, receptor and ligand files, PyMOL scripts and sessions, and distinct images. Files are arranged by the original question and analysis step. Run PyMOL scripts from their own directories; shared inputs are addressed through relative paths.

Identical SwissDock water-condition exports are stored in `Q2/Q2_3/`: the docking result and receptor coordinates are in `PLIP Input/`, while force-field and receptor files are in `1R4L_protein_zn_water/files/`. Other docking variants retain their distinct outputs. Docking and structural calculations were not rerun during preparation.

***This repository contains coursework for educational purposes only and should not be treated as a rigorously validated academic reference.***
